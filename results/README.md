# Saved evidence
Original JSON and CSV artifacts retain their run IDs and source checksums.
run_index.csv indexes original/relevance traces and distinguishes small smoke
runs from 40-group runs. RQ2 results include small and larger learning runs
and two diagnostic subsets; do not pool these as independent replications.
RBS results include 2-graph smoke and 40-graph cohorts.

Summaries verify metadata and recorded scalar results. They are not raw traces.
The original four-model combined tables, order-control contrast tables and
some plotting inputs were not included by the collection allowlist.
Both SIM-CoT relevance full-run summaries are preserved without selecting one
as authoritative. Select by the report's provenance and full output records.
